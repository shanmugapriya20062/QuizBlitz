# QuizBlitz – Interactive Quiz Web Application

## About the Project
QuizBlitz is an interactive quiz application that helps users test their knowledge in HTML, CSS, JavaScript, and Java.

## Technologies Used
- HTML
- CSS
- JavaScript
- Java
- Spring Boot
- REST API

## Features
- Four quiz categories: HTML, CSS, JavaScript, and Java
- Five multiple-choice questions per category
- 15-second timer for each question
- Instant feedback for correct and incorrect answers
- Final score display

## Backend
The backend is developed using Java and Spring Boot. It provides quiz questions for all four categories through a REST API. The frontend fetches questions from the deployed backend.
